# RV60Bible (v3.0.0)

## Descripción
- Aplicación para leer la biblia de una manera fácil y rápida en un computadora o laptop.
- Deseñada para ejecutarse en equipos con _(Windows 10, Windows 11 o Linux)_ al ser una app nativa.
- Al usar la aplicación podrás acceder a distintas versiones de la biblia, que incluyen texto en _(Español)_ e _(Inglés)_.
- Donde puedes guardar tus versos favoritos, resaltarlos con diferentes colores y poder accederlos después.
- Una aplicación ligera con un diseño minimalista, que le permite una lectura cómoda.
- Cuenta con configuraciones para prevenir que se apague la pantalla, tamaño de letra y tema de color, ideal si estas _proyectando en la iglesia_.
<br/>

## Características
- Esta aplicación de la biblia cuenta con las siguientes versiones de texto:
    - **La Biblia de las Américas** _(rev. 1997)_
    - **Nueva Versión Internacional**  _(rev. 2015)_
    - **Palabra de Dios para todos** _(rev. 2012)_
    - **Reina Valera 2020** _(rev. 2020)_
    - **Reina Valera 1960** _(rev. 1960)_
    - **Reina Valera Contemporánea** _(rev. 2010)_
    - **English Standard Version** _(rev. 2016)_
    - **New International Version** _(rev. 2011)_
    - **The Holy Bible New King James Version** _(rev. 1982)_
- Todas las versiones incluyen los _66_ libros de la biblia:
    - **39** para el _antiguo testamento_
    - **27** para el _nuevo testamento_
- Te ofrece opciones para añadir, ver o modificar tus versos favoritos al dar clic derecho sobre este.
- Cuenta también con una función para resaltar e identificar versos con distintos colores.
- Puedes usar la función de búsqueda por nombre de libro, número de capitulo y verso, o también búsqueda por palabras clave.
- El verso se resalta con color al posicionar el cursor sobre este, ideal para proyectar en la iglesia y seguir la lectura.
- Cuenta con controles de navegación para cambiar de libro o capítulo rápidamente.
- El título de la ventana cambia respecto al libro y capítulo que se visualiza.
- Selección del tema de color incorporado:
    - **claro** con visuales _cálidos_
    - **oscuro** con visuales _fríos_
- Cuenta con atajos del teclado para:
    - Regresar la navegación ```Alt + Arrow Left```
    - Activar pantalla completa ```F11```
- Si encuentras un error en los textos puedes reportar el contenido del verso en el menú al hacer clic derecho sobre el verso.
<br/>

## Actualización (v2.0.2 -> v3.0.0)
La actualización incluye los siguientes cambios:
- Se añadieron 3 versiones de texto en Inglés _(ESV, NIV, NKJV)_
- El cambio de tamaño de letra ahora se puede controlar más específicamente con botones
- Se añadió la configuración que previene que se apague la pantalla por inactividad _(ahora es configurable)_
- Se mejoró el menú para seleccionar la versión de la biblia que se visualiza
- Se rediseñaron los controles de navegación
- Se rediseñó la ventana de ajustes
- Se refactorizó el funcionamiento interno de la aplicación
- Se corrigieron bugs y se mejoró el rendimiento de la aplicación

> [!IMPORTANT]
> **WINDOWS**

1. Descarga el instalador más reciente desde [aquí](https://github.com/Gama19999/electron-rv60bible/releases)
2. Para realizar la instalación en un equipo con Windows ejecuta (dar doble clic) el archivo descargado:
```sh
rv60bible_3.0.0_installer.exe
```
3. Puede personalizar la instalación con el directorio destino, el menú de inicio y el acceso directo de escritorio. Una vez concluido, la aplicación estará disponible para su uso.

> [!IMPORTANT]
> **WINDOWS (Portable)**
- También puedes descargar el archivo _standalone_ que es una versión portable del software que puedes colocar en cualquier directorio sin la necesidad de instalar la aplicación.
- Al descomprimir en un equipo con Windows ejecuta (dar doble clic) el archivo:
```sh
rv60bible.exe
```
