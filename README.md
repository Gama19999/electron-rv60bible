# Biblia RV60 (v1.2.0)

## Descripción
- Aplicación para leer la biblia en la versión Reina Valera 1960 de una manera fácil y rápida en un computadora o laptop con la opción para guardar tus versos favoritos y poder accederlos después.
- Una aplicación ligera con un diseño minimalista en forma de libro, lo que permite una interacción más realista como si fuera un libro real.
<br/>

## Características
- Versión del texto **Reina Valera 1960**
- Incluye los 66 libros (**39 AT** | **27 NT**)
- Función para visualizar **10**, **8** o **5** _versos por página_
- Establecer y remover versos como marcadores
- Visualización del texto en diseño de páginas de libro
- Texto sobresaltado al posicionar el cursor sobre el verso
- Acceso directo para cambio de libro o capítulo
- El titulo de la ventana cambia respecto al libro y capítulo que se visualiza 
- Función de pantalla completa
> [!TIP]
> Al visualizar 5 versos por página la fuente aumenta, ideal para proyeccción a pantalla
<br/>

## Instalación
> [!IMPORTANT]
> **Procedimiento en LINUX**

Para realizar la instalación en un equipo con Linux, este debe ser basado en **DEBIAN** y ejecutar el siguiente comando en la terminal:
```sh
sudo apt install ./rv60bible_1.2.0_amd64.deb
```
Una vez concluida la instalación, la aplicación estará disponible para su uso.
<br/><br/>
> [!IMPORTANT]
> **Procedimiento en WINDOWS**

Para realizar la instalación en un equipo con Windows se debe abrir (o dar doble clic) el archivo descargado :
```sh
rv60bible_1.2.0_win32.exe
```
Puede personalizar la instalación con el directorio destino, el menú de inicio y el acceso directo de escritorio. Una vez concluido, la aplicación estará disponible para su uso.
